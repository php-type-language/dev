The printer is the inverse of the [parser](/toolkit/parser/): it turns a
`TypeLang\Type\TypeNode` back into a string.

## Installation

```bash
composer require type-lang/printer
```

**Requirements:**
* `PHP >= 8.1`

## Quick start

Both printers implement `TypeLang\Printer\TypePrinterInterface` with a
single `print()` method:

```php
use TypeLang\Parser\TypeParser;
use TypeLang\Printer\NativeTypePrinter;
use TypeLang\Printer\PrettyTypePrinter;

$type = new TypeParser()->parse('non-empty-list<positive-int>|null');

new PrettyTypePrinter()->print($type);
// non-empty-list<positive-int>|null

new NativeTypePrinter()->print($type);
// array|null
```

<Aside type="tip">
A printer keeps no state between calls: create it once and reuse it.
</Aside>

## Choosing a printer

|                        | [Pretty](/toolkit/printer/pretty/) | [Native](/toolkit/printer/native/) |
|------------------------|-----------------------------|-----------------------------|
| **Goal**               | the type as it is, for a human | valid PHP syntax, for code |
| `array{id: int}`       | `array{id: int}`            | `array`                     |
| `int[]`                | `int[]`                     | `iterable`                  |
| `positive-int`         | `positive-int`              | `int`                       |
| `Foo::BAR`             | `Foo::BAR`                  | `mixed`                     |
| `int<0, max>`          | `int<0, max>`               | `int`                       |
| `$arg is null ? A : B` | `($arg is null ? A : B)`    | `A│B`                       |
| `?int`                 | `?int`                      | `int│null`                  |

## Formatting

Both printers take a `TypeLang\Printer\PrinterOptions`: line breaks,
indentation, spacing, the style of nullable types and lists. See the
[options](/toolkit/printer/pretty/#options).

```php
use TypeLang\Printer\PrettyTypePrinter;
use TypeLang\Printer\PrinterOptions;

$printer = new PrettyTypePrinter(new PrinterOptions(
    newLine: "\r\n",
    indentation: "\t",
));
```

## Error handling

A tree built by the parser is always printable. A node of a class the
printer does not know, such as a subclass of your own, throws a
`NonPrintableNodeException`. Every exception of the printer implements
`TypeLang\Printer\Exception\PrinterExceptionInterface`.
