The reader turns the **native** type of a reflected constant, property,
function or parameter into the same [AST](/toolkit/ast/) the
[parser](/toolkit/parser/) builds.

<Aside>
Only the native types are read. A `@var list<User>` of a docblock is read
by the [PHPDoc parser](/phpdoc/).
</Aside>

## Installation

```bash
composer require type-lang/reader
```

**Requirements:**
* `PHP >= 8.1`

## Reading types

Every method of `TypeLang\Reader\ReflectionReader` takes a Reflection object
and returns a `TypeNode`, or `null` when no type is declared. The results
below are shown as the [pretty printer](/toolkit/printer/pretty/) prints
them.

```php
final class Example
{
    public const int MAX = 100;

    public ?DateTimeInterface $bannedAt;

    public $untyped;

    public function find(Countable $items): Generator|false { /* ... */ }
}
```

```php
$reader = new TypeLang\Reader\ReflectionReader();

$reader->findConstantType(new ReflectionClassConstant(Example::class, 'MAX'));
// int

$reader->findPropertyType(new ReflectionProperty(Example::class, 'bannedAt'));
// ?\DateTimeInterface

$reader->findPropertyType(new ReflectionProperty(Example::class, 'untyped'));
// null

$method = new ReflectionMethod(Example::class, 'find');

$reader->findFunctionType($method);
// \Generator|false

$reader->findParameterType($method->getParameters()[0]);
// \Countable
```

`getType()` converts a `ReflectionType` you already hold:

```php
$reader->getType($method->getReturnType());
// \Generator|false
```

## How types are converted

| PHP                      | AST                                          |
|--------------------------|----------------------------------------------|
| `Example`                | `\Example`: a class name is fully qualified  |
| `int`, `static`, `mixed` | as written                                   |
| `?Foo`, `Foo\|null`      | `?\Foo`: a `NullableTypeNode`                |
| `A\|B`                   | a `UnionTypeNode`                            |
| `A&B`                    | an `IntersectionTypeNode`                    |
| no type                  | `null`, not `mixed`                          |

## Read vs. Write

Since PHP 8.4 a `set` hook may take another type than the property gives.
The second argument of `findPropertyType()` selects the side:

```php
final class Post
{
    public string $slug {
        set(string|Stringable $value) {
            $this->slug = (string) $value;
        }
    }
}

$property = new ReflectionProperty(Post::class, 'slug');
```

<Tabs>
<TabItem label="Read (default)">
```php
$reader->findPropertyType($property);
// string
```
</TabItem>

<TabItem label="Write">
```php
use TypeLang\Reader\PropertyAccessDirection;

$reader->findPropertyType($property, PropertyAccessDirection::Write);
// \Stringable|string
```
</TabItem>
</Tabs>

A property without a typed `set` hook gives its read type for both.

## Error handling

Every exception of the reader implements
`TypeLang\Reader\Exception\ReaderExceptionInterface`. A `ReflectionType` of
an unknown kind throws an `UnrecognizedReflectionTypeException`, which tells
what type it is and where it is declared:

```php
use TypeLang\Reader\Exception\UnrecognizedReflectionTypeException;

try {
    $reader->findPropertyType($property);
} catch (UnrecognizedReflectionTypeException $e) {
    $e->type;      // the ReflectionType
    $e->reflector; // the ReflectionProperty
}
```

| Property     | Type              | Value                                                        |
|--------------|-------------------|--------------------------------------------------------------|
| `$type`      | `ReflectionType`  | the type that is not recognized                              |
| `$reflector` | `Reflector\|null` | the property, parameter, function or constant it is declared on, `null` for `getType()` |
