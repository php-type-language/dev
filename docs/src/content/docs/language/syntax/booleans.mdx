A literal is a type of exactly one value. The words `true` and `false` are the
two values of the PHP `bool` type, `null` is the only value of the `null`
type. [Strings](/language/syntax/strings/) and
[numbers](/language/syntax/numbers/) are literals too.

<TypeTree type="TruE">
`true` and `false` are not case sensitive.
</TypeTree>

<TypeTree type="NulL">
`null` is not case sensitive either.
</TypeTree>

These three words are literals only on their own: as a part of a name or with
a namespace they are [ordinary names](/language/syntax/names/) (`true-type`,
`true\null`).
