A type may carry comments. They are read as whitespace: they separate tokens
and mean nothing of their own.

- A **line comment** begins with `//` or `#` and runs to the end of the line.
- A **block comment** begins with `/*` and runs to the next `*/` inclusive.

<Tabs>
<TabItem label="Examples">
<TypeTree type="int /* comment */ | string">
A block comment between two tokens.
</TypeTree>

A line comment ends a line of a type written across several:

```php
int | // comment
    string
```

```php
# comment
int
```

</TabItem>
