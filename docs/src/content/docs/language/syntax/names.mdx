A type name is written the way PHP writes an
[identifier](https://www.php.net/manual/en/language.variables.basics.php),
with one difference: a dash (`-`) may stand inside a name.

- The first character is a letter or an underscore (`_`).
- The rest are letters, digits, underscores and dashes, a dash cannot be the
  last character.
- A letter is `a-z`, `A-Z` or a byte from `0x80` to `0xff`.
- A dash is allowed only in a name without a namespace: `non-empty-string` is
  a name, `Some\non-empty-string` and `non-empty\Some` are not.

The words `true`, `false` and `null` in any case are
[literals](/language/syntax/booleans/), not names, when they stand alone.

<Aside>
The words `is`, `not`, `of`, `as`, `super`, `covariant`, `contravariant` and
`invariant` mean something only where the grammar expects them, like `is` in
a [conditional type](/language/syntax/conditionals/). Anywhere else they are
ordinary names, and in upper case (`IS`, `OF`) they are always names.
</Aside>

## Namespace

A name may carry a namespace, separated with a backslash (`\`) the
[way PHP does it](https://www.php.net/manual/en/language.namespaces.rationale.php).
A backslash may stand inside a name or at its start, not at its end. With a
namespace, the reserved words are ordinary names.

## The $this type

The `$this` variable denotes the type of the object the type is written on. It
is a type of its own, so it stands wherever a type stands: inside a union,
behind a question mark, or as the type a
[callable](/language/syntax/callables/) returns.

<Aside>
`$this` is the one variable that is a type. Any other variable names a
[callable parameter](/language/syntax/callables/#named-parameters) or an operand of a
[conditional type](/language/syntax/conditionals/), and is not a type on its own.
</Aside>
