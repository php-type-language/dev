A **platform** is a bundle of [tag definitions](/phpdoc/extending/definitions/), aliases
and [combinators](/phpdoc/extending/combinators/) — everything needed to teach the parser a
family of tags.

A platform implements `PlatformInterface`, three methods, each returning an
`iterable`. The abstract `Platform` base class implements all three as empty,
so a platform extends it and overrides only what it contributes:

```php
final class MoneyPlatform extends Platform
{
    public function getTags(): iterable
    {
        return [
            MoneyTagDefinition::getCanonicalName() => new MoneyTagDefinition(),
        ];
    }
}
```

* **`getTags()`** — [definitions](/phpdoc/extending/definitions/), keyed by each tag's
  canonical name.
* **`getAliases()`** — alternative-spelling to canonical-name pairs, both
  lower-case (this is how `@template-implements` is treated as `@implements`, for instance).
* **`getCombinators()`** — any [combinator](/phpdoc/extending/combinators/) the definitions
  reference that is not built in already, keyed by name. A value is a
  `CombinatorInterface` implementation or any `callable(Cursor): mixed`.

<Aside>
`MoneyTagDefinition` only leans on the built-in `Integer`
and `Name` combinators, so its platform contributes none of its own.
A platform adds combinators only when its tags introduce grammar the parser
does not already provide — see
[Writing One of Your Own](/phpdoc/extending/combinators/#writing-one-of-your-own).
</Aside>

Tag names and aliases are matched case-insensitively: a definition registered
as `inheritDoc` also answers to `@inheritdoc`.

## Registering it

The platform is handed to `DocBlockParser`'s constructor:

```php
$parser = new DocBlockParser(platforms: [
    new MoneyPlatform(),
]);

$block = $parser->parse('/** @money 100 USD */');
```

The parser loads exactly the platforms it is given, in order: a later platform
overrides an entry of an earlier one only when it reuses the same tag, alias or
combinator name. Every platform is self-contained, so `MoneyPlatform` alone
yields a parser that knows `@money` and nothing else (any other tag is read as a
plain `Tag`).

<Aside>
`new DocBlockParser()` with no arguments loads **no** platform at
all. To load every built-in one (Standard, phpDocumentor, Psalm, PHPStan, Phan,
PhpStorm and PHP CodeSniffer), use the
`DocBlockParser::createDefault()` factory. No tag name is shared by
two built-in platforms, so the order they are loaded in does not matter:

```php
$parser = DocBlockParser::createDefault();
```

To register your own platform on top of the built-in tool families, pass it to
`createDefault()` via the `$additionalPlatforms` argument —
it is appended after the built-in platforms, so it extends them and overrides an
entry only when it reuses the same name:

```php
$parser = DocBlockParser::createDefault(additionalPlatforms: [
    new MoneyPlatform(),
]);
```

</Aside>

The definitions that end up registered are exposed as `$parser->tags` (a
countable, iterable `TagRegistryInterface`), and the factory that builds tags
from them as `$parser->factory`.

<Aside type="tip">
A `DocBlockParser` builds its whole tag and type grammar once, in its
constructor, and is otherwise stateless. Construct it once — platforms and
all — and reuse it across the application rather than per docblock.
</Aside>
