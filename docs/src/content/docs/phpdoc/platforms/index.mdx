A platform is a set of tags the parser knows: their
[definitions](/phpdoc/extending/definitions/), aliases and
[combinators](/phpdoc/extending/combinators/).

```php
use TypeLang\PhpDoc\DocBlockParser;

// every built-in platform
$parser = DocBlockParser::createDefault();

// every built-in platform and your own
$parser = DocBlockParser::createDefault(additionalPlatforms: [
    new MoneyPlatform(),
]);

// only the given ones: any other tag is a plain Tag
$parser = new DocBlockParser(platforms: [
    new StandardPlatform(),
    new PhpStanPlatform(),
]);
```

<Aside type="caution">
`new DocBlockParser()` without arguments loads **no** platform at all.
</Aside>

A later platform overrides a tag, an alias or a combinator of an earlier
one with the same name. No name is shared by two built-in platforms, so
their order does not matter. The names are matched without regard to case.

<Aside type="tip">
The parser builds its grammar once, in the constructor: create it once and
reuse it.
</Aside>

## Built-in platforms

| Platform                 | Tags                                                |
|--------------------------|-----------------------------------------------------|
| `StandardPlatform`       | [Standard](/phpdoc/platforms/standard/) and [Advanced](/phpdoc/platforms/advanced/) |
| `PhpDocumentorPlatform`  | [phpDocumentor](/phpdoc/platforms/phpdocumentor/)   |
| `PhpStanPlatform`        | [PHPStan](/phpdoc/platforms/phpstan/) and the `@phpstan-` spellings of the shared tags |
| `PsalmPlatform`          | [Psalm](/phpdoc/platforms/psalm/) and the `@psalm-` spellings |
| `PhanPlatform`           | [Phan](/phpdoc/platforms/phan/) and the `@phan-` spellings |
| `PhpStormPlatform`       | [PhpStorm](/phpdoc/platforms/phpstorm/)             |
| `PhpCodeSnifferPlatform` | [PHP CodeSniffer](/phpdoc/platforms/phpcs/)         |

## Custom platform

A platform extends `Platform` and overrides what it adds:

```php
use TypeLang\PhpDoc\Platform\Platform;

final class MoneyPlatform extends Platform
{
    // definitions by the name of the tag
    public function getTags(): iterable
    {
        return ['money' => new MoneyTagDefinition()];
    }

    // other spellings of a tag: @price is read as @money
    public function getAliases(): iterable
    {
        return ['price' => 'money'];
    }

    // combinators the definitions use, by their names
    public function getCombinators(): iterable
    {
        return [PriorityCombinator::NAME => new PriorityCombinator()];
    }
}
```

A combinator is a `CombinatorInterface` or any `callable(Cursor): mixed`.
See [custom tags](/phpdoc/extending/custom-tags/) for the whole way from a
tag to a platform.

The registered definitions are `$parser->tags`, a countable and iterable
`TagRegistryInterface`.
