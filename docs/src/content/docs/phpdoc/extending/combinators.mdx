A combinator reads one piece of a tag line: a type, a variable, a URI. A
[grammar](/phpdoc/extending/grammar/) refers to it by name:
`Spec::rule(TypeCombinator::NAME, 'type')`.

```php
interface CombinatorInterface
{
    public function __invoke(Cursor $cursor): mixed;
}
```

A combinator reads its part from the `Cursor` and returns the value, or
calls `$cursor->fail()`: the grammar then rolls the cursor back and
tries the next alternative.

| `Cursor` method                               | Reads                                  |
|-----------------------------------------------|----------------------------------------|
| `peek($length)`, `read($length)`              | a number of bytes, without or with moving |
| `readWhile($chars)`, `readUntil($chars)`      | a run of, or up to, the characters     |
| `readWord()`                                  | up to the next whitespace              |
| `readPhpIdentifier()`, `readPhpQualifiedName()` | a name, without or with `\`          |
| `readLiteral($text)`                          | the exact text, `false` when it is not next |
| `readRemainder()`                             | everything left                        |
| `skipWhitespace()`, `isEof()`                 |                                        |
| `fail($message)`                              | nothing: rejects the input             |

## Built-in combinators

| Name            | Returns                | Reads                                       |
|-----------------|------------------------|---------------------------------------------|
| `Type`          | `TypeReference`        | a [TypeLang type](/language/)               |
| `CallableType`  | `TypeReference`        | a [callable type](/language/syntax/callables/) |
| `Variable`      | `string`               | a `$name`, without the `$`                  |
| `Name`          | `string`               | an identifier                               |
| `Integer`       | `int`                  | a non-negative integer                      |
| `Reference`     | `CodeReference`        | a class, function, method, constant, property or variable |
| `AssertSubject` | `CodeReference`        | `$value`, `$this->items`, `$this->getItems()`, `self::$instances` |
| `URI`           | `UriReference`         | a word of RFC 3986                          |
| `URL`           | `UrlReference`         | a URL of WHATWG with a host                 |
| `Version`       | `string`               | a word beginning with a digit               |
| `IssueName`     | `string`               | letters, digits, `_`, `-` and `.`           |
| `Description`   | `DescriptionInterface` | everything left, with its inline tags       |
| `Visibility`    | `Visibility`           | `public`, `protected` or `private`          |
| `AuthorName`    | `string`               | everything up to an optional `<`            |
| `Email`         | `string`               | an address, up to its closing `>`           |
| `FlowType`      | `FlowType`             | a taint flow kind of Psalm                  |

<Aside>
`Visibility`, `AuthorName` and `Email` are added by `PhpDocumentorPlatform`,
`FlowType` by `PsalmPlatform`, the others are given to every platform by the
parser. `Type` and `CallableType` read types by the `TypeParser` of
`DocBlockParser`. `Description` cannot be redefined.
</Aside>

## Writing one of your own

A combinator reading a `low` or `high` priority:

```php
enum Priority: string
{
    case Low = 'low';
    case High = 'high';
}

final class PriorityCombinator implements CombinatorInterface
{
    public const string NAME = 'Priority';

    public function __invoke(Cursor $cursor): Priority
    {
        return Priority::tryFrom($cursor->readWord())
            ?? $cursor->fail('Expected a priority level');
    }
}
```

It is registered by a [platform](/phpdoc/platforms/) and used as a built-in
one:

```php
final class PriorityPlatform extends Platform
{
    public function getCombinators(): iterable
    {
        return [PriorityCombinator::NAME => new PriorityCombinator()];
    }

    // ...
}

// "@priority" <Priority>
Spec::rule(PriorityCombinator::NAME, 'priority');
```

```php
$parser->parse('/** @priority high */')[0];
// PriorityTag { priority: Priority::High }

$parser->parse('/** @priority urgent */')[0];
// InvalidTag: Malformed "@priority" tag, expected: <Priority>
```

<Aside type="tip">
Read only your own syntax: the whitespace between the parts of a grammar is
skipped by `Spec::sequence()`. When the input does not fit, call
`$cursor->fail()` instead of guessing: another alternative of
`Spec::oneOf()` may take it.
</Aside>

<Aside type="caution">
Only `$cursor->fail()` turns the tag into an `InvalidTag`. Any other
exception of a combinator, and a grammar that refers to an unregistered
combinator, is thrown by the parser.
</Aside>
