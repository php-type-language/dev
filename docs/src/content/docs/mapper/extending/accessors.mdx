A field of a mapped class is read by a reader and written by a writer. They
are chosen by a strategy once per field, on the first conversion of the
class.

The [metadata](/mapper/metadata/) give each field of the data its access:
the backing value of a property (`SlotAccessMetadata`), its PHP 8.4 hook
(`HookAccessMetadata`) or a method (`MethodAccessMetadata`). By default the
backing value is written directly or by reflection for private and readonly
properties, bypassing its hooks, a virtual property is accessed through its
hooks, a method is called.

An access strategy takes a field of the normalization
(`OutputFieldMetadata`) or of the denormalization (`InputFieldMetadata`) and
returns the reader or the writer, or `null` for an access it does not take.
A strategy may take one direction only. Strategies of the user are tried
first.

A strategy that goes through the getter and the setter of a property:

```php
use TypeLang\Mapper\Mapping\Metadata\Access\SlotAccessMetadata;
use TypeLang\Mapper\Mapping\Metadata\Field\InputFieldMetadata;
use TypeLang\Mapper\Mapping\Metadata\Field\OutputFieldMetadata;
use TypeLang\Mapper\PropertyAccessor\PropertyReader\MethodPropertyReader;
use TypeLang\Mapper\PropertyAccessor\PropertyReaderInterface;
use TypeLang\Mapper\PropertyAccessor\PropertyWriter\MethodPropertyWriter;
use TypeLang\Mapper\PropertyAccessor\PropertyWriterInterface;
use TypeLang\Mapper\PropertyAccessor\Strategy\AccessStrategyInterface;

final class AccessorMethodsStrategy implements AccessStrategyInterface
{
    public function tryCreateReader(
        \ReflectionClass $class,
        OutputFieldMetadata $field,
    ): ?PropertyReaderInterface {
        $access = $field->access;

        // only a property with its own value
        if (!$access instanceof SlotAccessMetadata) {
            return null;
        }

        $method = 'get' . \ucfirst($access->property);

        if (!$class->hasMethod($method)) {
            return null;
        }

        return new MethodPropertyReader($method);
    }

    public function tryCreateWriter(
        \ReflectionClass $class,
        InputFieldMetadata $field,
    ): ?PropertyWriterInterface {
        // the same with the "set" prefix and MethodPropertyWriter
    }
}
```

```php
final class Customer
{
    public string $name;

    public function getName(): string { /* ... */ }

    public function setName(string $name): void
    {
        $this->name = \strtolower($name);
    }
}

$mapper = new Mapper(accessors: [new AccessorMethodsStrategy()]);

$mapper->denormalize(['name' => 'JOHN'], Customer::class);
// Customer { name: 'john' }
```

The strategy chooses how to execute the access, not the fields of the data:
which fields are mapped and under which names is decided by the metadata.
The value reaches the writer already converted to the type of the field.

<Aside>
Read and write a property the same way. A getter that changes the value, such
as one returning `ucfirst($this->name)`, makes a normalized object
denormalize into another one.
</Aside>
