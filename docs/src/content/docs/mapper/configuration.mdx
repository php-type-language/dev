Configuration is a `TypeLang\Mapper\Configuration` DTO passed to the
`TypeLang\Mapper\Mapper` constructor.

```php
use TypeLang\Mapper\Configuration;
use TypeLang\Mapper\Mapper;

$mapper = new Mapper(
    config: new Configuration(
        // options = true|false
        // default = false
        strict: false,

        // options = true|false
        // default = true
        normalizeAsArray: true,

        // options = int<1, max>
        // default = 1
        maxViolations: 1,

        // options = true|false
        // default = false
        rejectExtraFields: false,

        // options = int<0, max>
        // default = 1
        expectedTypeDepth: 1,

        // options = int<1, max>|null
        // default = null
        expectedTypeMaxFields: null,
    ),
);
```

<Aside type="tip">
Create the mapper once and reuse it (for example, as a service of your
container): it parses and builds every type only once.
</Aside>

## Strict

Disables [type coercion](/mapper/coercion/) on denormalization: `'42'` is
no longer an `int`.

<Tabs>
<TabItem label="strict: false (default)">
```php
$mapper = new Mapper(new Configuration(strict: false));

$mapper->denormalize(42, 'int');                               // 42
$mapper->denormalize('42', 'int');                             // 42
$mapper->denormalize(1, 'bool');                               // true
$mapper->denormalize(42, 'float');                             // 42.0
$mapper->denormalize((object) ['id' => 42], 'array{id: int}'); // ['id' => 42]
```
</TabItem>

<TabItem label="strict: true">
```php
$mapper = new Mapper(new Configuration(strict: true));

$mapper->denormalize(42, 'int');                               // 42
$mapper->denormalize('42', 'int');
// throws InvalidValueException: $: Value must be of type int, but "42" given

$mapper->denormalize(1, 'bool');
// throws InvalidValueException: $: Value must be of type bool, but 1 given

$mapper->denormalize(42, 'float');                             // 42.0
$mapper->denormalize((object) ['id' => 42], 'array{id: int}'); // ['id' => 42]
```
</TabItem>
</Tabs>

<Aside>
Even in strict mode an `int` is accepted as a `float`,
a `stdClass` as an array, and the keys of arrays are converted.
A single property can override the option with
[metadata](/mapper/metadata/types/#strict-types).
</Aside>

## Normalize as array

Whether objects are normalized into associative arrays or into
`stdClass`.

```php
final class User
{
    public string $name = 'Alice';
}
```

<Tabs>
<TabItem label="normalizeAsArray: true (default)">
```php
$mapper = new Mapper(new Configuration(normalizeAsArray: true));

$mapper->normalize(new User()); // ['name' => 'Alice']
```
</TabItem>

<TabItem label="normalizeAsArray: false">
```php
$mapper = new Mapper(new Configuration(normalizeAsArray: false));

$mapper->normalize(new User()); // (object) ['name' => 'Alice']
```
</TabItem>
</Tabs>

<Aside>
A single class can override it with
[metadata](/mapper/metadata/misc/#normalize-as-array).
</Aside>

## Max violations

How many errors are collected before denormalization fails. By default it
fails on the first one. Normalization always fails on the first one.

<Tabs>
<TabItem label="maxViolations: 1 (default)">
```php
$mapper = new Mapper(new Configuration(maxViolations: 1));

$mapper->denormalize(['a', 2, 'c', 'd'], 'list<int>');
// throws InvalidValueException:
// $[0]: Value must be of type int, but "a" given
```
</TabItem>

<TabItem label="maxViolations: 2">
```php
$mapper = new Mapper(new Configuration(maxViolations: 2));

$mapper->denormalize(['a', 2, 'c', 'd'], 'list<int>');
// throws InvalidValueException:
// $[0]: Value must be of type int, but "a" given (and 1 more)
```
</TabItem>

<TabItem label="maxViolations: 100">
```php
$mapper = new Mapper(new Configuration(maxViolations: 100));

$mapper->denormalize(['a', 2, 'c', 'd'], 'list<int>');
// throws InvalidValueException:
// $[0]: Value must be of type int, but "a" given (and 2 more)
```
</TabItem>
</Tabs>

See [collecting violations](/mapper/errors/#collecting-violations) to read
all of them.

## Reject extra fields

Rejects fields that no property of a class (or field of a sealed shape)
takes. By default they are ignored.

```php
final class User
{
    public string $name;
}
```

<Tabs>
<TabItem label="rejectExtraFields: false (default)">
```php
$mapper = new Mapper(new Configuration(rejectExtraFields: false));

$mapper->denormalize(['name' => 'Alice', 'age' => 42], User::class);
// User { name: 'Alice' }
```
</TabItem>

<TabItem label="rejectExtraFields: true">
```php
$mapper = new Mapper(new Configuration(rejectExtraFields: true));

$mapper->denormalize(['name' => 'Alice', 'age' => 42], User::class);
// throws InvalidValueException: $.age: Unexpected field "age"
```
</TabItem>
</Tabs>

<Aside>
The field of a [discriminator](/mapper/metadata/discriminator/)
is not an extra field.
</Aside>

## Expected type depth

How many levels of classes the [messages](/mapper/errors/#messages) describe
by their fields. By default `1`: the fields of a class, its nested classes
are `object`. `0` describes a class as `object`.

```php
final class User
{
    public string $name;
    public ?Address $address = null;
}

final class Address
{
    public string $city;
}
```

<Tabs>
<TabItem label="expectedTypeDepth: 0">
```php
$mapper = new Mapper(new Configuration(expectedTypeDepth: 0));

$mapper->denormalize('x', User::class);
// throws InvalidValueException: $: Value must be of type object, but "x" given
```
</TabItem>

<TabItem label="expectedTypeDepth: 1 (default)">
```php
$mapper = new Mapper(new Configuration(expectedTypeDepth: 1));

$mapper->denormalize('x', User::class);
// throws InvalidValueException:
// $: Value must be of type object{name: string, address?: ?object},
// but "x" given
```
</TabItem>

<TabItem label="expectedTypeDepth: 2">
```php
$mapper = new Mapper(new Configuration(expectedTypeDepth: 2));

$mapper->denormalize('x', User::class);
// throws InvalidValueException:
// $: Value must be of type
// object{name: string, address?: ?object{city: string}}, but "x" given
```
</TabItem>
</Tabs>

## Expected type max fields

How many fields of a class the messages show, the others are `...`. By
default all of them.

<Tabs>
<TabItem label="expectedTypeMaxFields: null (default)">
```php
$mapper = new Mapper(new Configuration(expectedTypeMaxFields: null));

$mapper->denormalize('x', User::class);
// throws InvalidValueException:
// $: Value must be of type object{name: string, address?: ?object},
// but "x" given
```
</TabItem>

<TabItem label="expectedTypeMaxFields: 1">
```php
$mapper = new Mapper(new Configuration(expectedTypeMaxFields: 1));

$mapper->denormalize('x', User::class);
// throws InvalidValueException:
// $: Value must be of type object{name: string, ...}, but "x" given
```
</TabItem>
</Tabs>

## Other arguments

```php
use TypeLang\Mapper\Configuration;
use TypeLang\Mapper\Mapper;
use TypeLang\Mapper\Mapping\MetadataBuilder;
use TypeLang\Parser\TypeParser;
use TypeLang\Printer\PrettyTypePrinter;

$mapper = new Mapper(
    config: new Configuration(),
    builders: [/* TypeBuilderInterface */],
    hooks: [/* ClassHookInterface */],
    decorators: [/* TypeDecoratorInterface */],
    expanders: [/* TypeExpanderInterface */],
    accessors: [/* AccessStrategyInterface */],
    instantiators: [/* InstantiationStrategyInterface */],
    coercers: [/* 'int' => CoercerInterface, ... */],
    metadata: MetadataBuilder::createDefault()->build(),
    denormalizationFormatter: null, // ViolationFormatterInterface
    normalizationFormatter: null,   // ViolationFormatterInterface
    printer: new PrettyTypePrinter(),
    parser: new TypeParser(),
);
```

What each argument does and where it is called: see
[how the mapper works](/mapper/extending/#extension-points).
