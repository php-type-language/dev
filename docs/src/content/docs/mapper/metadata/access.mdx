A field of the data is read from and written to a member of the class. By
default a property is read and written through its backing store, its
hooks are not called, a virtual property is not mapped.

`#[MapGetter]` declares the read, `#[MapSetter]` the write. The member
takes part only in the declared directions, the place of the attribute
chooses the access:

| Attribute on   | Access                                        |
|----------------|-----------------------------------------------|
| a property     | the backing store, past the hooks             |
| a hook         | the hook                                      |
| a method       | the method, a field of its own                |

<Aside type="caution">
A property with `#[MapGetter]` only is not written: `denormalize()` leaves
it with its default value or uninitialized, the output of `normalize()`
does not come back. Give `#[MapSetter]` next to it for both directions.
</Aside>

## Property

The value is read and written past the hooks, such as on restoring an
object from storage.

- A private property with an attribute is mapped, a private property of a
  parent too, even next to a property of the same name in the child.
- A static property is an error.
- In a config the name of a property is a property of the class itself: a
  private property of a parent hidden by it is declared by attributes only.
<Tabs syncKey="metadata">
<TabItem label="Attributes">
```php
use TypeLang\Mapper\Mapping\MapGetter;
use TypeLang\Mapper\Mapping\MapSetter;

final class User
{
    #[MapGetter('created_at')]
    public \DateTimeImmutable $createdAt;

    #[MapSetter(onUndefinedError: 'Password is required')]
    private string $password;

    #[MapGetter, MapSetter('login', aliases: ['email'])]
    public string $name;
}

$mapper->normalize($user);
// ['created_at' => '...', 'name' => 'john']

$mapper->denormalize(['password' => 'x', 'email' => 'john'], User::class);
// User { password: 'x', name: 'john' }
```
</TabItem>

<TabItem label="PHPDoc">
<Aside type="caution">
Not supported.
</Aside>

</TabItem>

<TabItem label="Reflection">
<Aside type="caution">
Not supported: a property is read and written through its backing store.
</Aside>

</TabItem>

## Methods

A method with an attribute is a field of its own, not bound to a property.
The name of the field is required.

- The method is public, neither the constructor nor a magic method.
- A getter takes no required arguments and returns a value.
- A setter takes one value, not a variadic one. A setter with an optional
  parameter is not called when the data has no field, the `default` key of
  a config is passed to it.
<Tabs syncKey="metadata">
<TabItem label="Attributes">
```php
use TypeLang\Mapper\Mapping\MapGetter;
use TypeLang\Mapper\Mapping\MapSetter;

final class User
{
    private string $first = '';
    private string $last = '';

    #[MapGetter('full_name')]
    public function getFullName(): string
    {
        return $this->first . ' ' . $this->last;
    }

    #[MapSetter('full_name', type: 'non-empty-string')]
    public function setFullName(string $name): void
    {
        [$this->first, $this->last] = \explode(' ', $name, 2);
    }
}

$mapper->normalize($user);
// ['full_name' => 'John Doe']
```
</TabItem>

<TabItem label="PHPDoc">
<Aside type="caution">

`@param` of the setter.
</Aside>

</TabItem>

<Aside type="caution">

</Aside>

</TabItem>

## Hooks

`#[MapGetter]` on the `get` hook and `#[MapSetter]` on the `set` hook
access the property through the hook, with the type of the hook. A virtual
property is mapped only so.
<Tabs syncKey="metadata">
<TabItem label="Attributes">
```php
use TypeLang\Mapper\Mapping\MapGetter;
use TypeLang\Mapper\Mapping\MapSetter;

final class Post
{
    public string $title = '' {
        #[MapGetter]
        get => \ucfirst($this->title);
        #[MapSetter]
        set(string|int $value) {
            $this->title = (string) $value;
        }
    }

    public string $slug {
        #[MapGetter]
        get => \strtolower($this->title);
    }
}

$mapper->normalize($post);
// ['title' => 'Hello', 'slug' => 'hello']
```
</TabItem>

<TabItem label="PHPDoc">
<Aside type="caution">
Not supported: the types are read from `@return` of the `get` hook and
`@param` of the `set` hook, then from `@var` of the property in case of
the hook takes the native type of the property.
</Aside>

</TabItem>

<TabItem label="Reflection">
<Aside type="caution">
Not supported: the hooks are not called.
</Aside>

</TabItem>

## Arguments

| `#[MapGetter]` | `#[MapSetter]` | Config key |
|---|---|---|
| `name` | `name` | `name` |
| `type` | `type` | `type` |
| | `strict` | `strict` |
| | `aliases`, `onConflict` | `aliases`, `alias_conflict` |
| | `onTypeError` | `type_error_message` |
| | `onUndefinedError` | `undefined_error_message` |

## Rules

- Skip conditions are given next to the read: `#[SkipWhenNull]` on the
  property, the getter or the `get` hook, the `skip` key in `get`.
- A config key of a property without `get` and `set` applies to both
  directions, next to `get` or `set` it is an error.
- `#[MapName]`, `#[MapType]`, `#[MapAlias]`, `#[OnTypeError]` and
  `#[OnUndefinedError]` next to `#[MapGetter]` or `#[MapSetter]`, on a
  method or on a hook are errors: give their values in the arguments.
- An attribute of a direction the member does not declare, such as
  `#[SkipWhenNull]` next to `#[MapSetter]` only, is an error. An attribute
  of a direction left out by a config is not applied.
- The arguments are values like the others: a source of a higher priority
  overrides them, of a lower one it does not. A source declaring the
  directions (the attributes of the access, the `get` and `set` keys)
  declares the member as a whole: the directions of a lower source are
  replaced, not joined.
- PHP does not inherit attributes: a method or a hook overridden in a
  subclass, an abstract method and a method of an interface need their own
  `#[MapGetter]` or `#[MapSetter]`, otherwise the field is not mapped.
- The fields are written once all the values of the data are accepted: a
  setter or a hook is not called when another field is rejected.
