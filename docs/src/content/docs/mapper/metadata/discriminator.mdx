Polymorphism: the class of the data is selected by the value of a field.

Every option is shown in each [metadata source](/mapper/metadata/): choose
the tab of the source you use. When a source cannot express an option, its
tab says what is used instead.

## Declaring the map

The map is declared on a base class or an interface. A type of the map is
a class or an interface, another type is an error of the metadata.
<Tabs syncKey="metadata">
<TabItem label="Attributes">
```php
use TypeLang\Mapper\Mapping\DiscriminatorMap;

#[DiscriminatorMap(field: 'type', map: [
    'circle' => Circle::class,
    'square' => Square::class,
])]
abstract class Shape {}

final class Circle extends Shape
{
    public float $radius;
}

final class Square extends Shape
{
    public float $side;
}
```
</TabItem>

<TabItem label="PHPDoc">
<Aside type="caution">
There is no PHPDoc tag for this option.
</Aside>

</TabItem>

<TabItem label="Reflection">
<Aside>
PHP has no such declaration: the data is mapped to the declared class itself.
</Aside>

</TabItem>

### Field of the tag

A field of a class with the name of the field of the tag takes the tag.

```php
final class Circle extends Shape
{
    public string $type = 'round';
    public float $radius;
}

$mapper->normalize($circle);
// ['type' => 'circle', 'radius' => 2.0]

$mapper->denormalize(['type' => 'circle', 'radius' => 2], Circle::class);
// Circle { type: 'circle', radius: 2.0 }

$mapper->denormalize(['type' => 'square', 'side' => 2], Circle::class);
// throws InvalidValueException:
// $.type: Value must be of type 'circle', but "square" given
```

## Fallback type

The `otherwise` type is used when the tag is missing or unknown.

    'circle' => Circle::class,

abstract class Shape {}

    public float $radius;

## Normalization

The tag of the class is written as the first field. A subclass that is not
in the map, such as a proxy, is normalized as its nearest parent in the map:
with its tag and its fields only, the data is read back as that parent.

```php
use TypeLang\Mapper\Mapping\DiscriminatorMap;

#[DiscriminatorMap(field: 'type', map: ['circle' => Circle::class])]
abstract class Shape {}

class Circle extends Shape
{
    public float $radius = 1.5;
}

final class CircleProxy extends Circle {}

$mapper->normalize(new Circle(), Shape::class);
// ['type' => 'circle', 'radius' => 1.5]

$mapper->normalize(new CircleProxy(), Shape::class);
// ['type' => 'circle', 'radius' => 1.5]
```

The tag does not depend on the type passed: the class of the object has it.

```php
$mapper->normalize(new Circle());
// ['type' => 'circle', 'radius' => 1.5]
```

Several maps in the hierarchy write their tags, the root one first. Two maps
that give the class different tags in one field are an error of the type.

A class that is not in the map and has no parent in it is not normalized.
With `otherwise` it is normalized without the tag.

```php
$mapper->normalize(new Hexagon(), Shape::class);
// throws InvalidValueException:
// $: Class "Hexagon" has no tag in the discriminator map of "Shape"
```

## Classes of the hierarchy

Any class of the hierarchy can be the type, such as of a property. It takes
the classes of the map that are the class or its children, an object is
normalized the same as through the base.

```php
#[DiscriminatorMap(field: 'type', map: ['square' => Square::class])]
abstract class Shape {}

class Polygon extends Shape { public int $corners = 4; }

class Square extends Polygon { public int $side = 2; }

$mapper->normalize(new Square(), Polygon::class);
// ['type' => 'square', 'side' => 2, 'corners' => 4]

$mapper->denormalize(['type' => 'square'], Polygon::class); // Square

$mapper->denormalize(['type' => 'circle'], Polygon::class);
// throws InvalidValueException:
// $.type: Value must be of type 'square', but "circle" given
```

A class of the map takes the data without the tag too, the tag of another
class is an error:

```php
$mapper->denormalize(['side' => 2, 'corners' => 4], Square::class);
// Square { side: 2, corners: 4 }

$mapper->denormalize(['type' => 'circle'], Square::class);
// throws InvalidValueException:
// $.type: Value must be of type 'square', but "circle" given

$mapper->denormalize(['corners' => 4], Polygon::class);
// throws InvalidValueException: $.type: Required field "type" is missing
```

A class outside the map without children in it takes no data: reading it
is an error of the type.

```php
$mapper->denormalize(['edges' => 6], Hexagon::class);
// throws TypeDefinitionException: Class "Hexagon" is not in the
// discriminator map of "Shape": neither it nor its children have a tag
```

A class with its own property named as the tag field writes that property,
the tag is not added.
