Other options of classes, properties and enums.

Every option is shown in each [metadata source](/mapper/metadata/): choose
the tab of the source you use. When a source cannot express an option, its
tab says what is used instead.

## Normalize as array

Normalizes objects of the class into an associative array (`true`) or into
`stdClass` (`false`). Overrides the
[configuration option](/mapper/configuration/#normalize-as-array).
<Tabs syncKey="metadata">
<TabItem label="Attributes">
```php
use TypeLang\Mapper\Mapping\NormalizeAsArray;

#[NormalizeAsArray(false)]
final class User
{
    public string $name = 'Ada';
}
```
</TabItem>

<TabItem label="PHPDoc">
<Aside type="caution">
There is no PHPDoc tag for this option.
</Aside>

</TabItem>

<TabItem label="Reflection">
<Aside>
PHP has no such declaration: the [configuration option](/mapper/configuration/#normalize-as-array) is used.
</Aside>

</TabItem>

<TabItem label="PHP Config">
```php
<?php

return [
    App\User::class => [
        'normalize_as_array' => false,
    ],
];
```
</TabItem>

<TabItem label="JSON">
```json
{
    "App\\User": {
        "normalize_as_array": false
    }
}
```
</TabItem>

<TabItem label="YAML">
```yaml
App\User:
    normalize_as_array: false
```
</TabItem>

<TabItem label="NEON">
```yaml
App\User:
    normalize_as_array: false
```
</TabItem>

</Tabs>

```php
$mapper->normalize(new User()); // (object) ['name' => 'Ada']
```

## Default value

The value of a missing field. A property without a default value is
required.
<Tabs syncKey="metadata">
<TabItem label="Attributes">
<Aside type="caution">
There is no attribute for a default value: it is written in PHP, see the Reflection tab.
</Aside>

</TabItem>

<TabItem label="PHPDoc">
<Aside type="caution">
There is no PHPDoc tag for a default value: it is written in PHP, see the Reflection tab.
</Aside>

</TabItem>

<TabItem label="Reflection">
```php
final class User
{
    public string $name;
    public string $role = 'user';
}
```
</TabItem>

<TabItem label="PHP Config">
```php
<?php

return [
    App\User::class => [
        'properties' => [
            'role' => [
                'default' => 'user',
            ],
        ],
    ],
];
```
</TabItem>

<TabItem label="JSON">
```json
{
    "App\\User": {
        "properties": {
            "role": {
                "default": "user"
            }
        }
    }
}
```
</TabItem>

<TabItem label="YAML">
```yaml
App\User:
    properties:
        role:
            default: user
```
</TabItem>

<TabItem label="NEON">
```yaml
App\User:
    properties:
        role:
            default: user
```
</TabItem>

</Tabs>

<Tabs syncKey="data">
<TabItem label="Valid data">
```php
$mapper->denormalize(['name' => 'Ada'], User::class);
// User { name: 'Ada', role: 'user' }
```
</TabItem>

<TabItem label="Invalid data">
```php
$mapper->denormalize(['role' => 'admin'], User::class);
// throws InvalidValueException: $.name: Required field "name" is missing
```
</TabItem>
</Tabs>

<Aside>
A promoted property takes the default value of its constructor parameter.
A default value is `null`, a scalar, an enum case or an array of
them: an object, such as `new Address()` in an initializer, is an
error of the metadata. `null` in the data is a value, not a
missing field: it must match the type.
</Aside>

## Value aliases

Other values accepted for a case of a backed enum, such as old values.
Normalization always gives the value of the case.
<Tabs syncKey="metadata">
<TabItem label="Attributes">
```php
use TypeLang\Mapper\Mapping\MapAlias;

enum Status: string
{
    #[MapAlias(['enabled', 'on'])]
    case Active = 'active';

    case Blocked = 'blocked';
}
```
</TabItem>

<TabItem label="PHPDoc">
<Aside type="caution">
There is no PHPDoc tag for this option.
</Aside>

</TabItem>

<TabItem label="Reflection">
<Aside>
Only the values of the cases are accepted.
</Aside>

</TabItem>

<TabItem label="PHP Config">
```php
<?php

return [
    App\Status::class => [
        'aliases' => [
            'enabled' => 'active',
            'on' => 'active',
        ],
    ],
];
```
</TabItem>

<TabItem label="JSON">
```json
{
    "App\\Status": {
        "aliases": {
            "enabled": "active",
            "on": "active"
        }
    }
}
```
</TabItem>

<TabItem label="YAML">
```yaml
App\Status:
    aliases:
        enabled: active
        'on': active
```
</TabItem>

<TabItem label="NEON">
```yaml
App\Status:
    aliases:
        enabled: active
        on: active
```
</TabItem>

</Tabs>

```php
$mapper->denormalize('on', Status::class); // Status::Active
$mapper->normalize(Status::Active);        // 'active'
```
